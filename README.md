# Fruit-Classification-Freshness-Grade
A deep learning system that identifies fruit and vegetable types and estimates freshness levels score 0 - 1 using computer vision and PyTorch. Uses YOLO for object detection and a ResNet18-based CNN for produce classification and freshness estimation.
